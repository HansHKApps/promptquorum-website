# Translation check: "Explain this" privacy paragraph

For a native speaker. Compare your language with the English source below. Please check:

1. Does it say the same thing as the English, with nothing added or left out (especially the limits 600 and 3,500 characters, and that selecting text alone sends nothing)?
2. Is it natural, formal enough for a privacy policy, and consistent in how it addresses the reader?
3. Does the button name match the button on the website in your language?

Write your corrections under your language. Live page: https://www.promptquorum.com/privacy (add /de, /fr, /ja, /zh, /es, /pt, /ar or /ko before /privacy).

## English (source)

“Explain this” button: if you mark text on one of our pages or in an Ask Hans answer and click “Explain this”, we additionally transmit, in the same way, the marked text (up to 600 characters), text surrounding it (up to 3,500 characters, for example neighbouring paragraphs and the section heading and, for short terms, an earlier passage in which the term appears), and the title and path of the page. Marking text alone sends nothing. The surrounding text is used to create that answer and does not become part of your conversation; the marked text appears in it as your question. If this text contains personal data, for example in something you entered that is shown on the page or in a chat answer, it is transmitted too, so please do not use the button there.

## German

Das Markieren allein sendet nichts. Der umgebende Text dient dazu, diese Antwort zu erzeugen, und wird nicht Teil Ihres Gesprächs; der markierte Text erscheint darin als Ihre Frage. Enthält dieser Text personenbezogene Daten, etwa in einer auf der Seite oder in einer Chat-Antwort angezeigten Eingabe von Ihnen, werden sie mitübermittelt; bitte nutzen Sie die Schaltfläche dort nicht.
